# Tugas 2 - Pemrograman Mobile

Repositori ini memuat implementasi **Tugas 2** yang terdiri dari dua proyek:

1. **`aplikasi_stok/`**
   - Aplikasi Manajemen Gudang & Operasi Matematika berbasis **Dart Console (CLI)** murni dengan arsitektur **Object-Oriented Programming (OOP)**.
   - Mengimplementasikan 6 kriteria tugas (Login, Data Kelompok, Penjumlahan & Pengurangan Stok dengan JSON, Perkalian & Pembagian Kapasitas Rak, Cek Ganjil/Genap Stok & Bilangan, serta Total/Statistik Angka).

2. **`aplikasi_stok_android/`**
   - Proyek aplikasi mobile berbasis **Android / Flutter** untuk aplikasi manajemen stok.
